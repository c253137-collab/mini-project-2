## 📖 About the Project

A single-page **student portfolio website** developed for **CSE-2340 Mini Project 2**. It introduces the developer, showcases skills and featured projects, and includes a contact form, all in a lightweight, mobile-friendly layout styled with **Tailwind CSS**.

## ✨ Features

- 📱 Fully responsive (mobile, tablet, desktop)
- 🧭 Sticky navigation bar with smooth scrolling
- 🍔 Mobile hamburger menu (JavaScript)
- 🦸 Hero section with intro, buttons and profile picture
- 🧠 About & Skills section
- 🗂️ Featured Projects grid with hover animations
- ✉️ Contact form with success feedback message

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| Tailwind CSS (CDN) | Styling and responsiveness |
| Vanilla JavaScript | Menu toggle and form feedback |
| Google Fonts (Inter) | Typography |
